# 手の撮影(Web アプリ)

カメラの映像から、手の点(21個)を見つけて、**手のひら・手の甲・指先(爪)**を、ガイドに合わせて、撮る Web アプリです。条件(手の向き、指が重なっていないか、近さ、明るさ、止まっているか、ピント)が、そろって、約1秒、保たれると、自動で撮ります(手動の「撮影」ボタンも、あります)。

- 映像と写真は、**この端末の中だけ**で、処理します。サーバーには、送りません。
- 撮影を助ける、ガイドです。**医療の判定では、ありません**。
- 手の検出に、Google の MediaPipe(Apache License 2.0)を、使っています。

## 動かし方(この PC で)

`run.bat` を、ダブルクリックします(Python が、必要です)。ブラウザが、開きます(`http://localhost:8784/`)。カメラの使用を、許可してください。止める時は、黒い窓で、Ctrl+C を、押します。

## 撮り方

1. 「手のひら」「手の甲」「指先」を、選びます(指先は、「5本まとめて / 1本ずつ」)。
2. 画面の、ガイドの文に、従って、手を動かします。条件が、そろうと、枠が緑になり、約1秒で、撮れます。
3. 「写真に保存」: iPhone は、共有の画面が、開きます(「画像を保存」)。PC は、ダウンロードです。
4. 撮影は、鏡に映さず、**カメラの、そのままの向き**で、保存します。

## 撮影のオン・オフ

判定の調整のため、**自動の撮影と「撮影」ボタンは、いま、オフ**です(撮ると、撮影後の画面に、切り替わって、検出が、止まるため)。条件が、そろうと、枠が緑になり、「そろいました(撮影は、いまは、オフです)」と出るだけです。撮影を、オンにするには、アドレスの末尾に `?capture=1` を付けて、開きます(例: `http://localhost:8784/?capture=1`)。

## 確認用の数字

画面の下の「確認用の数字」に、判定に使った数字が、出ます(手の左右、手のひらか甲か、大きさ、傾き、指の伸び・開き、明るさ、動き、ピント)。判定が、おかしい時の、手がかりに、なります。

## 試験

```
node guide_test.mjs        # 判定とガイド(人工の手の点で。画面なし)
node app_smoke_test.mjs    # 画面(ヘッドレス Edge + 偽のカメラ。本物の手のモデルが、動くかも、確かめる)
```

本物の手での、判定は、**人が、実際に、試して**、確かめます。手のひらか甲かは、最初、逆に出たので、手の左右のラベルの扱い(`RAW_FRAME`)を、直しました(2026-11-20)。

## 確かめたこと / 確かめていないこと

- 確かめた: Windows の Edge(自動試験。偽のカメラ、人工の手の点)。本物の MediaPipe の手のモデルが、読み込めて、動くこと。
- **確かめていない**: 本物の手での、判定(手のひらか甲か、指の開き、指先の大きさ、ピント)。iPhone の実機。
